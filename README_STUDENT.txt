CS 315 - Assignment 4 Student Starter
React Contact Directory

1. Extract this starter project to your local computer.
2. Open the project folder in VS Code.
3. Open Terminal -> New Terminal.
4. Run:
     npm.cmd install
5. Start the development server:
     npm.cmd run dev
6. Complete the TODO items in src/App.tsx and src/ContactCard.tsx.
7. Follow the HW4 PDF for the complete requirements and ICE deployment steps.

IMPORTANT:
- Do not install React/Vite on ICE for this assignment.
- Development and build happen on your local computer.
- Do not upload node_modules to Brightspace or ICE.
- Before ICE deployment, run npm.cmd run build and upload the CONTENTS of dist/.
